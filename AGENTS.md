# Instructions du projet LN-IA
Séance 04 : lundi 05 octobre 2026. Ne pas inventer l’horaire.
Public : candidats du Challenge 100 Jours, Relance Automne 2026.
Lire README.md et docs/CAHIER-ATELIER.md avant modification.
Utiliser les entrées fournies et nommer clairement les exemples fictifs.
Préserver les sept vues, les vingt écrans de présentation et le logo LN-IA.
Ne pas appeler une IA depuis le navigateur sans demande explicite. Ne pas introduire de clé, d’analytics ou de collecte distante.
La sauvegarde candidat est locale, déclenchée par un bouton. Toute extension doit maintenir une explication claire de la conservation et un effacement.
L’auto-évaluation ne vaut pas validation pédagogique. Ne pas inventer de signature, témoignage ou résultat.
Conserver les données privées et productions candidat réelles hors public/, dist/ et du dépôt. Le .gitignore ne protège pas les fichiers déjà suivis.
Ne pas effacer les modifications existantes. Vérifier git status et le diff avant commit.
Après modification : npm run check et npm run build. Tester les fonctions modifiées dans le navigateur.
Les exports doivent signaler les champs manquants. Ne pas transformer automatiquement un champ vide en preuve acquise.
Publication : suivre l’autorisation de la session. Le pack fourni est une préparation, pas un site déjà publié.
