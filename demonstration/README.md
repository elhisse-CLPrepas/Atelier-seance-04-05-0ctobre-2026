# Démonstration Samira Benali
Cas fictif préparé pour la séance du lundi 05 octobre 2026.
Les fichiers sont un scénario pédagogique. Le brouillon n’est pas présenté comme une sortie réelle de l’outil d’un candidat.

Plan : lire le cadrage, exécuter ou expliquer le prompt, repérer les erreurs, corriger, ouvrir le livrable et documenter le contrôle.
Temps : 1 + 2 + 2 + 3 + 2 = 10 minutes, inclus dans la phase de production.

Pour rejouer sans IA : `npm run demo`. Le script copie les fichiers préparés dans un nouveau dossier travail-local et produit un journal technique daté. Il n’exécute pas le prompt et n’attribue aucune validation pédagogique.
Pour un essai avec IA : utiliser 02-prompt.md dans l’assistant, conserver la réponse réellement obtenue et documenter vos corrections dans votre dossier local.
